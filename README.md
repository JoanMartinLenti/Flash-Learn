# Flash-Learn
Flash Learn is a web app that makes flashcards for study of languages.
The page has a creation section for collections, this collections can have flashcards with the word in the front and the meaning in the back.
The page use the collections to make a study program for the user. Before starting the user can choose the collections they want to use.
In the study section the user can choose if they got the word wrong or not. 
When the user finish the study the page collects all the answers and show the statistics in a diferent section showing the wrongs and the corrects.
The user can make a study sesion with only the words that they got wrong.
